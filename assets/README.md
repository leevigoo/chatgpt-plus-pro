# assets/ — 图片占位说明

4 个 README 引用了以下 4 张图，**请在发布前替换成你自己的实际截图**：

| 文件名 | 用途 | 建议尺寸 | 备注 |
| --- | --- | --- | --- |
| `step1.jpeg` | 第一步：下单成功 + 卡密验证页面 | 1280 × 720 左右 | 突出"卡密"字段和"验证卡密"按钮 |
| `step2.jpeg` | 第二步：填写邮箱 / 支付页面 | 1280 × 720 左右 | 可马赛克掉真实邮箱 |
| `step3.jpeg` | 第三步：ChatGPT 设置页显示 Plus 标识 | 1280 × 720 左右 | 证明升级成功 |
| `wechat-qr.jpg` | 微信客服二维码 | 600 × 600 左右，正方形 | 必须是活码 |

## 替换方法

1. 把同名文件拖进本目录覆盖即可，无需改 README。
2. 如果想换文件名，记得同步修改 4 个 README 里对应的 `![...](./assets/xxx.jpeg)` 路径（中 / 英 / 日 / 韩）。
3. JPEG / PNG / WebP 均可；单图控制在 500KB 以内，GitHub 仓库加载更快。

## 临时占位

如果暂时没图，可以用 [placehold.co](https://placehold.co) 占位：

```
https://placehold.co/1280x720?text=Step+1
```

正式发布前一定要换成真截图。
